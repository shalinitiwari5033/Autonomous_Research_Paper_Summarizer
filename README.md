📄 Autonomous Research Paper Summarizer

A Streamlit-based AI application that automatically extracts key sections—Methodology, Contributions, Results, and Summary—from any uploaded research paper PDF using a hybrid pipeline of PDF text extraction + rule-based NLP + optional OpenAI GPT enhancement.

🚀 Features

📥 Upload any research paper PDF

🔍 Automatic text extraction using PyPDF2 / pdfminer.six fallback

🧹 Text cleaning & preprocessing

🧠 Autonomous extraction of:

Methodology

Key Contributions

Results / Findings

Final Summary

🤖 Optional OpenAI GPT-based enhancement for high-quality output

🖥️ Interactive Streamlit UI with spinners for progress feedback

🔄 Generates the same output for the same input (deterministic unless GPT randomness is enabled)
